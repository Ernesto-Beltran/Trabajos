<br>

La etiqueta <br> inserta un salto de línea dentro del texto, sin crear un párrafo nuevo.

<hr>

La etiqueta <hr> representa una separación temática entre contenidos y se muestra como una línea horizontal.

<img>

La etiqueta <img> muestra una imagen. El atributo src indica su ubicación y alt ofrece un texto alternativo; es una etiqueta vacía y no necesita cierre.

<input>

La etiqueta <input> crea un control para que el usuario introduzca datos. El atributo type define el tipo de entrada y es una etiqueta vacía.

<link>

La etiqueta <link> relaciona el documento con un recurso externo, como una hoja de estilos. Se escribe en el <head> y no se muestra directamente; el siguiente ejemplo tiene estilos aplicados desde styles.css.

Este texto recibe sus estilos de una hoja CSS enlazada.

<meta>

La etiqueta <meta> aporta metadatos sobre la página, como su descripción, codificación o configuración de vista. Va en el <head> y no se muestra directamente.

<meta name="description" content="Página con ejemplos de etiquetas HTML de autocierre.">

<col>

La etiqueta <col> define propiedades para una o más columnas de una tabla. Se coloca dentro de <colgroup> y permite aplicar estilos a una columna completa.
