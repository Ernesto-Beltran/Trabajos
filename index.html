La etiqueta <hr> representa una separación temática entre contenidos y se muestra como una línea horizontal.

<img>

La etiqueta <img> muestra una imagen. El atributo src indica su ubicación y alt ofrece un texto alternativo; es una etiqueta vacía y no necesita cierre.

<input>

La etiqueta <input> crea un control para que el usuario introduzca datos. El atributo type define el tipo de entrada y es una etiqueta vacía.
